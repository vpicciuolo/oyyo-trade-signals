# Contributing

This repository accepts improvements to public customer documentation, examples, accessibility and non-sensitive issue reports.

- Keep claims consistent with the product boundaries.
- Do not claim guaranteed performance, personal recommendations or universal regulatory status.
- Distinguish simulated, paper and live-data provenance.
- Do not publish credentials, customer information, private repository content or proprietary implementation.
- Link to authoritative OYYO repositories and the live product website for changing facts.

Pull requests should describe the problem, proposed correction and source for factual changes. Use [SECURITY.md](SECURITY.md) for vulnerabilities and product support for account, billing or personal-data matters.
